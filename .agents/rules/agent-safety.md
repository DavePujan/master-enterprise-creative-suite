# Agent Safety Rules

## Read Before Write

Before modifying the project, always understand the relevant code and current architecture.

Never make unrelated changes.

Never modify files merely because doing so seems helpful.

Never perform destructive or irreversible actions without explicit user intent.

When the `/poojan` workflow is active, ALL project modifications are prohibited.

`/poojan` means:

FULL READ ACCESS
ZERO WRITE AUTHORITY

If there is uncertainty about whether an operation modifies project state, do not perform the operation.
